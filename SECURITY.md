# Security Policy

## Reporting a Vulnerability

Please do not disclose wallet vulnerabilities publicly before a fix is available.

Report privately to: security@blockzero.network (placeholder).

Include:

- Wallet version / commit
- Platform information
- Reproduction steps
- Security impact

## Response Targets

- Initial response: within 72 hours
- Triage decision: within 7 days
- Coordinated disclosure after patch release

## Scope

This repository includes key and transaction handling components and is high priority for security.
