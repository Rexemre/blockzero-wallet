# Contributing

Thanks for contributing to Block Zero Wallet.

## Ground Rules

- Security first.
- Keep changes focused and reviewable.
- Add tests for wallet behavior changes.
- Avoid investment language in docs and UI copy.

## Workflow

1. Open an issue for major changes.
2. Create a branch and implement.
3. Add/update tests and docs.
4. Open PR with risk notes and testing evidence.

## UX and Safety

User safety text should be clear and conservative:

- No guaranteed outcomes
- No profit claims
- Clear backup/recovery messaging
